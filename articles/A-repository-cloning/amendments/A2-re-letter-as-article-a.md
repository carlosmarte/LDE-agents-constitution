# A2 — Re-letter Article I as Article A

- **Date:** 2026-11-07
- **Status:** Adopted
- **Changes:** Renames every citation of this article; no rule changes.

## Reason

The constitution moved from numbered articles to lettered ones, which caps the base at 26 articles (see [AGENTS.md](../../../AGENTS.md), "The 26-article limit"). This article was the first, so it became Article A.

Amendment [A1](A1-adopt-article.md) keeps its original text, so it still uses the old citations. They map as follows:

| Old | New |
|---|---|
| Article I, folder `01-repository-cloning` | Article A, folder `A-repository-cloning` |
| `I.<s>.<c>` (clauses, e.g. `I.3.2`) | `A.<s>.<c>` (e.g. `A.3.2`) |
| `I-L01` … `I-L05` | `A-L01` … `A-L05` |
| `I-P01`, `I-P02` | `A-P01`, `A-P02` |
| `I-A0001`, file `A0001-adopt-article.md` | `A1`, file `A1-adopt-article.md` |
